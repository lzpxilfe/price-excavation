# ASOS 관측소 레지스트리

이 디렉터리는 외부 API 키가 없어도 현장 좌표에서 최근접 종관기상관측(ASOS) 지점을 고를 수 있도록 기상청 지점 메타데이터를 버전별로 고정합니다. 현재 게시본은 `asos-2026-08-10.json`이며, 공식 ASOS 분류 코드 `SFC01`의 응답 105건 중 종료일이 없는 현재 지점 97건을 보존합니다.

## 1차 출처

- 기상청 국가기후데이터센터 [관측지점정보](https://data.kma.go.kr/tmeta/stn/selectStnList.do?pgmNo=123): 지점번호, 시작·종료일, 위·경도와 지점 이전 이력을 조회·CSV 다운로드할 수 있습니다.
- 기상청 국가기후데이터센터 [종관기상관측(ASOS)](https://data.kma.go.kr/data/grnd/selectAsosRltmList.do?pgmNo=36): `SFC01`이 ASOS 자료 화면임을 확인하고 현재 제공 지점 집합을 정합니다.
- 키 없는 공식 JSON 응답은 `POST https://data.kma.go.kr/cmmn/stnGroupPopupAjax.do`에 다음 form 값을 보내 수집합니다.

```text
stns=
stnGrpSn=
mddlClssCd=SFC01
serviceSe=F00102
searchKeyword=
```

## 갱신·검증 절차

1. 위 POST 응답의 SHA-256과 전체 건수를 기록합니다.
2. `endDate == "12월 31, 2100"`인 현재 행만 남기고 `stnId`를 문자열 `id`로 변환합니다.
3. `id` 중복, 빈 좌표, 대한민국 범위 밖 좌표를 차단합니다. 이 게시본은 전체 105건, 현재 97건, 중복 0건, 빈 좌표 0건입니다.
4. KMA 지점 상세화면의 `좌표(WGS84)`와 `id`, `name`, `latitude`, `longitude`를 대조하고, 관측지점정보 CSV로 이전 이력을 확인합니다. CSV는 소수 넷째 자리로 반올림되거나 상세화면과 최대 약 `0.0003°` 차이가 날 수 있습니다. 예를 들어 강진군(259)은 이전 좌표 `34.6289, 126.7672`가 아니라 현재 상세 좌표 `34.64457, 126.78408`과 일치해야 합니다.
5. 현장 좌표와 각 지점의 대권거리(Haversine)를 계산해 오름차순으로 정렬합니다. 최근 5개 완전연도 관측이 모자라면 임의 보간하지 않고 다음 후보를 시도하거나 수동 입력으로 전환합니다.

기상청은 동일 지점번호도 기간에 따라 위치가 달라질 수 있다고 안내합니다. 이 레지스트리는 최근접 지점 선택을 위한 **현재 위치 스냅샷**이며, 과거 관측값의 역사적 위치를 복원하는 자료가 아닙니다.
